# Support Policy

Thank you for using **Auto Optional Chainer**! We are committed to making this project reliable, safe, and easy to use.

## Getting Help

### 💬 GitHub Discussions & Questions

If you have questions about how to use the extension, configure keyboard shortcuts, or want to discuss ideas:

- Please open a discussion in [GitHub Discussions](https://github.com/tafsirc/auto-optional-chainer/discussions).
- Check the [README](README.md) for configuration and usage instructions.

### 🐛 Bug Reports

If you found a bug or unexpected behavior:

1. Check existing [GitHub Issues](https://github.com/tafsirc/auto-optional-chainer/issues) to ensure it has not already been reported.
2. If it's a new bug, submit a report using the [Bug Report Form](https://github.com/tafsirc/auto-optional-chainer/issues/new?template=bug_report.yml) with reproducible code snippets.

### 💡 Feature Requests

Have an idea or want support for a new framework or syntax?

- Submit a proposal using the [Feature Request Form](https://github.com/tafsirc/auto-optional-chainer/issues/new?template=feature_request.yml).

### 🔒 Security Vulnerabilities

Please **do not report security vulnerabilities through public GitHub issues**.

- Follow the process outlined in our [Security Policy](SECURITY.md).
- Email [tafsircy@gmail.com](mailto:tafsircy@gmail.com) directly.
