## [0.0.6] - 2025-02-11

### Added

- Initial release of AutoOptionalChainer
- Support for JavaScript, TypeScript, JSX, and TSX files
- Auto optional chaining application with smart detection
- Configuration options:
  - Auto-apply on file save
  - Keyboard shortcut support (Ctrl+Shift+O / Cmd+Shift+O)
- Extended list of ignored identifiers including Math, Number, String, Date, React, Object, Array, RegExp, JSON
- Template literal support with interpolation processing
