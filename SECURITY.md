# Security Policy

## Supported Versions

We actively support the latest released version of Auto Optional Chainer.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |
| < 0.0.7 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:

1. **Do not create a public issue.**
2. Send an email to [tafsircy@gmail.com](mailto:tafsircy@gmail.com) with details about the vulnerability, steps to reproduce, and potential impact.
3. You can also use [GitHub Private Vulnerability Reporting](https://github.com/tafsirc/auto-optional-chainer/security/advisories/new) if enabled.

We will review the report, acknowledge receipt within 48 hours, and work on a fix as quickly as possible.
